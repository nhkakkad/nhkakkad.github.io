Admin Setup

Configure your Google Sheets connection once. Settings are saved in this browser.

Create a Google Sheet, then open Extensions → Apps Script and paste the code from apps-script.gs.

In Apps Script: Deploy → New deployment → Web app → Anyone → Deploy. Copy the Web App URL.

Set a SECRET_TOKEN inside the script. Use the same value below. Also set a password for this admin panel.

Settings stored only in this browser's localStorage. Not sent anywhere.
